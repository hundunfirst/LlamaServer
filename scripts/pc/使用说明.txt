Bonsai 本地模型 —— 傻瓜式使用说明
====================================

这个文件夹可以整体搬走
----------------------
你可以把整个文件夹（llama\ models\ 和这几个文件）剪切到桌面、D 盘、U 盘都行，
所有路径都是相对的，换位置不影响。

注意两点：
  1) 搬之前先把黑窗口关掉（服务在跑时文件被占用，Windows 会搬不完整）
  2) 桌面如果在 OneDrive 同步范围内，会被自动上传（几 GB 会很慢）

第一次用（三步）
----------------
  1) 双击 启动Bonsai.bat
  2) 菜单里输入序号选模型 → 回车
  3) 等窗口出现 listening on http://0.0.0.0:8081，浏览器打开 http://127.0.0.1:8081/
     停止：关闭黑窗口，或按 Ctrl+C

菜单长这样：
   可选主模型：
    [1] Ternary-Bonsai-2-4B-PQ2_0.gguf
        1.07 GB   视觉：Ternary-Bonsai-2-4B-mmproj-Q8_0.gguf
   已跳过（不能当主模型）：
    - Ternary-Bonsai-2-9B-DFlash2-Q8_0.gguf（draft）
   输入序号（回车 = 上次的 1，q 退出）

  · 视觉自动配对：同系列同尺寸的 *-mmproj-*.gguf 会配上
  · 投机解码草稿自动配对：同尺寸的 *-DFlash2-* / *-dspark-* / *-MTP-* 会配上，
    菜单显示"草稿：xxx"，启动时自动加 --spec-draft-model / --spec-type / --spec-draft-n-max
    （不想要：把 start-bonsai.ps1 顶部 USE_DRAFT 设 0）
  · 草稿/侧车永远不会被当成主模型
  · 回车 = 上次选的那个（记在 last-run.txt）
  · 名字对不上时，在 start-bonsai.ps1 顶部的 $ProjectorOverride / $DraftOverride 里
    手动写一行配对（例：MiniCPM-V-4_7-1B-F16.gguf = mmproj-model-f16-4x.gguf）

想一键启动某个模型（不经过菜单）
--------------------------------
在本文件夹建个快捷方式，目标填（注意引号）：
    "C:\…\Bonsai\启动Bonsai.bat" -Model "Ternary-Bonsai-2-4B-PQ2_0.gguf"
其它可选参数：
    -Projector none      不用视觉
    -Draft none          不用草稿（投机解码）
    -Draft "xxx.gguf"    手动指定草稿

在手机上用（可选）
------------------
  1) start-bonsai.ps1 顶部 HOST_ADDR 保持 0.0.0.0，APIKEY 填一个只有你知道的字符串
  2) 电脑和手机连同一个 WiFi
  3) 电脑上 ipconfig 看 IPv4 地址，比如 192.168.31.132
  4) 手机 App → 设置 → 模型渠道 → 新增：
        地址：http://192.168.31.132:8081
        密钥：和你填的 APIKEY 一样
        模型：随便填（比如 local）
  注意：HOST=0.0.0.0 且 APIKEY 留空，同网段任何人都能用你的电脑跑模型。

想让它能看图（视觉）
--------------------
  · 主模型和投影器都放 models\ 里，菜单自动配对
  · 投影器文件名里一定有 "mmproj"，而且必须同尺寸（4B 配 4B，9B 配 9B）
  · 显存只有 4GB 时保持 MMPROJ_ON_CPU = 1（投影器放内存，纯文字不受影响）
  · 千万别把 *-DFlash2-*.gguf / *-dspark-*.gguf / *-MTP-*.gguf 当投影器，那些是草稿模型

关于"草稿"文件（投机解码）
--------------------------
  · *-DFlash2-* / *-dspark-* / *-MTP-* 是**给主模型加速用的草稿**，单独加载会报错
    （dflash requires ctx_other to be set），所以必须配一个同尺寸的主模型
  · 主模型和草稿的尺寸要一致，不然 fork 会直接崩（不是报错退出，是异常终止）
  · 少了主模型时它们就是闲置的：9B 的草稿要配 9B 主模型才有用

改参数
------
全部参数都在 start-bonsai.ps1 顶部（端口 / 上下文 / GPU层数 / 线程 / 监听地址 / 令牌 /
投影器放内存 / 是否用草稿 / 草稿预测长度）。改完保存，重新双击即可。
启动文件是 ASCII 的批处理，避免用记事本改成乱码。

出问题了
--------
  · 提示找不到模型        → 看 models\ 里文件名
  · 提示地址已被占用      → 端口改成 8082、8083
  · 启动一半退出、提示显存 → 上下文 CTX 调小（8192→4096），或 GPU层数 NGL 调小（99→20→0）
  · 想纯 CPU 跑           → NGL 设 0，慢但一定能起
  · 想看每个文件是什么    → 命令行跑：
        powershell -ExecutionPolicy Bypass -File start-bonsai.ps1 -Diagnose
  · 想看会执行什么命令    → 同上参数换成 -DryRun
  · 完整日志              → 同目录 run.log（脚本流程）和 server.log（服务输出）

速度参考（这台电脑，RTX 2050 4GB）
----------------------------------
  4B PQ2_0 全量上卡、上下文 8192：约 60~66 tok/s
  同一台机器纯 CPU：约 10~14 tok/s
